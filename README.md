## Prompts

### Prompt Engineering Tips

1. **Be specific** - Clear instructions get better results
2. **Provide context** - Background info improves accuracy
3. **Use examples** - Show the AI what you want
4. **Iterate** - Refine your prompts based on outputs

### Useful Prompts

**For Coding:**
```
Act as a senior software engineer. Review this code for bugs, security issues, and performance improvements: [code]
```

**For Writing:**
```
You are a professional copywriter. Write a compelling product description for [product] that highlights [benefits] and appeals to [target audience].
```

**For Analysis:**
```
Analyze this data and provide: 1) Key insights 2) Trends 3) Recommendations. Data: [paste data]
```
